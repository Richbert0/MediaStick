LAN Match Nicht verbunden

Memory fuer zwei Spieler im selben Netzwerk.

Ein Host erstellt den Raum, der zweite Spieler tritt per Code bei. Karten, Punkte, Spielzug und Siegstatus werden synchron gehalten und bleiben auf kleinen wie grossen Bildschirmen gut lesbar.

Abwechselnde Zuege Nur der aktive Spieler darf Karten aufdecken. Treffer bringen Punkte und einen weiteren Versuch.
Synchrones Board Der Host verwaltet das Match und uebertraegt jeden Karten- und Punktestand an alle Teilnehmer.
Responsive Layout 4x4 und 4x6 Modi mit skalierenden Karten, grosser Statusanzeige und Touch-freundlichen Abstaenden.
